# C2M + Jaspersoft Skill Matrix

## Core Tracks
1. CISADM Data Modeling
- Level 1: table identification and key joins
- Level 2: status/lookup enrichment and language handling
- Level 3: cardinality-risk mitigation and lineage evidence

2. SQL Engineering
- Level 1: readable business-safe SQL
- Level 2: reconciliation and parity frameworks
- Level 3: performance-tuned CTE/subquery patterns with explain-plan evidence

3. Jaspersoft Domain + JRXML
- Level 1: domain-field selection and input controls
- Level 2: domain-first report construction with guardrails
- Level 3: production-safe deployment/versioning and rollback controls

4. Performance & Reliability
- Level 1: baseline timing capture
- Level 2: optimization with zero-diff validation
- Level 3: standardized playbooks with automated regression checks

## Monthly Targets
- Ship at least 2 validated SQL performance improvements with zero business deltas.
- Publish at least 1 reusable domain/report pattern with documentation.
- Complete 1 explain-plan deep-dive review and archive results.
