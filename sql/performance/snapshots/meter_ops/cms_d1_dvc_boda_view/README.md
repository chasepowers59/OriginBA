# CMS_D1_DVC_BODA_VW (legacy device BO data-area overlay)

Standard Offering Device Domain expects `CISADM.CMS_D1_DVC_BODA_VW`.

This view extracts latest BO status and retirement datetime from `D1_DVC.BO_DATA_AREA` at device grain.
