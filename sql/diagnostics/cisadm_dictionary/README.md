# CISADM Dictionary Discovery Pack (Read-Only)

This pack extracts Oracle metadata for the `CISADM` schema using only read-only dictionary views.

## Outputs
- `tables.csv`
- `columns.csv`
- `constraints.csv`
- `constraint_columns.csv`
- `indexes.csv`
- `index_columns.csv`
- `views.csv`
- `view_dependencies.csv`
- `mviews.csv`
- `synonyms_to_cisadm.csv`
- `table_partitions.csv`
- `table_stats.csv`
- `column_stats.csv`
- `fk_join_map.csv`
- `keyword_table_map.csv`
- `index_columns_enriched.csv` (generated by the runner)
- `prefilter_candidates.csv` (generated by the runner)
- `prefilter_candidates_summary.md` (generated by the runner)
- `prefilter_top_by_table.md` (generated by the runner)

## Runner (PowerShell)
`scripts/performance/run_cisadm_dictionary_discovery.ps1`

## Runner (named client export, scripts 07-15)
```bash
python3 scripts/local/export_cisadm_dictionary_outputs.py --client demo
```

Writes CSV outputs under `output/cisadm_dictionary/`.

## Workstream table health (live COUNT)
```bash
python3 scripts/local/run_workstream_table_health.sh demo
```

Generates `sql/diagnostics/cisadm_workstream_table_health.sql` and
`deploy/snapshot_rollout_logs/<client>/table_health.json` for AI context merge.

## Run
Use the PowerShell runner:

```powershell
pwsh -File scripts/performance/run_cisadm_dictionary_discovery.ps1 `
  -ConnectString "user/password@host:1521/service"
```

Or run directly in SQL*Plus/SQLcl from this folder:

```sql
@00_extract_all_sqlplus.sql
```

## Safety
- No DDL, DML, or transactional writes.
- No statistics operations.
- Uses `ALL_*` dictionary views only.
