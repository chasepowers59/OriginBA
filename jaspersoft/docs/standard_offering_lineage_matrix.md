# Standard Offering Lineage Matrix

## Scope

This matrix ties key Standard Offering report endpoints to:

- target repository report URI
- target Domain URI
- governed snapshot table(s) backing that Domain (where snapshot-backed)
- primary Oracle source tables for the snapshot fact

Primary references:

- `deploy/jaspersoft_standard_offering/standard_offering_package_audit.json`
- `deploy/jaspersoft_standard_offering/standard_offering_verification.json`
- `sql/performance/snapshots/docs/workstream_snapshot_catalog.md`
- `sql/performance/snapshots/docs/snapshot_xml_inventory.md`

## Notes and caveats

1. The matrix uses target URIs from the package audit and verification artifacts, which are the deployment endpoint source-of-truth for Standard Offering.
2. Snapshot-to-domain mapping is canonical for snapshot-named domains (for example `Financial_Transaction_Snapshot___Domain`, `Measurement_Snapshot___Domain`) and inferred for legacy-named domains whose semantics match snapshot docs (`Collection_Process_Domain`, `Payment_Tender___Domain`, `SA_Snapshot___Aged_Balance___Domain`).
3. For non-snapshot workstreams (`common`, `customer_ops`, `field_ops`, `new_services`) many reports are currently domain/report driven without a governed snapshot table, so they are intentionally excluded from this snapshot lineage matrix.
