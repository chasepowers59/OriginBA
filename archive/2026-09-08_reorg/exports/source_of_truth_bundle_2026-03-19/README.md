# Source of Truth Bundle

## Purpose
This folder is a curated export pack of the most important source-of-truth and reference documents in this repository for Oracle C2M, CISADM, and Jaspersoft reporting work.

## What Is Included

### `source_of_truth/`
These are the highest-priority source files.

- `workstream_reporting_dictionary.json`
  - curated workstream-to-table mapping
- `Domain Designs.xlsx`
  - main design workbook referenced as a source of truth
- `domain_designs_metadata.json`
  - extracted metadata snapshot derived from the workbook

### `core_references/`
These are the most important operating guides and technical reference docs.

- `c2m_jaspersoft_delivery_playbook.md`
- `jaspersoft_domain_report_build_standards.md`
- `sql_quality_workflow.md`
- `jaspersoft_artifact_model_and_performance.md`
- `jaspersoft_charts_visuals_jrs9.md`
- `jaspersoft_dynamic_features.md`
- `oracle_c2m_query_patterns.md`
- `validation_playbook.md`
- `cisadm_core_model.md`
- `dictionary_coverage.md`

### `domain_artifacts/`
These are the main exported or extracted domain assets available in the repo.

- `FinalDomain.zip`
- `New Bill Cycle Domain.zip`
- `New Export Billing.zip`
- `Billing_Requirements_Domain_v2.schema.data`
- `New_Bill_Cycle_Domain.schema.data`

### `learning_guides/`
These are the study/reference guides created from the repository sources.

- `c2m_cisadm_analyst_handbook.md`
- `cisadm_workstream_vocabulary_guide.md`
- `cisadm_sql_cheat_sheet.md`
- `cisadm_workstream_study_deck.md`
- `cisadm_relationship_map.md`
- `cisadm_starter_sql_patterns.md`

## Why These Were Chosen
This bundle is based on:
- the explicit `Source of Truth` section in `AGENTS.md`
- the explicit `Operating References` section in `AGENTS.md`
- the key CISADM and SQL/Jaspersoft knowledge-base documents already used in this repo
- the main exported domain assets currently available in the workspace
